# Maintaining this environment source

This is the reusable environment SOURCE, not a hardware project. Never install
this environment into itself. Read README.md before editing.

Keep all shipped content project-independent: no project identifiers, local
paths, measured project results, design source, old histories or copied legacy
agent controls. Keep only portable preferences, pitfalls, general roles, skills,
policies, templates and tooling. Installation starts with empty project memory.

Read general/code-style/INDEX.md and general/code-pitfall/INDEX.md before design
or infrastructure changes. Preserve the user's established portable preferences.
For incoming local-project proposals, use the env-curator procedure and require
explicit approval of each external diff. Do not automatically commit or push.

Do not add docs/, backups/, validation/, tests/, examples/ or packaged duplicate
skills to this source tree. README.md is the operating guide. Run development
checks in disposable directories outside this tree. Do not launch vendor tools
or claim live Codex execution from file/schema checks.

Transfer intentionally replaces old project agent controls, including AGENTS.md,
without backups or rollback. Keep exact deletion scope and knowledge relocation
explicit; never interpret it as deleting source code, fixtures or all project docs.
Keep third-party notices without project-specific provenance identifiers.
